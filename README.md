## 🌟 About The Project

This portfolio is not just a collection of projects—it's a demonstration of modern frontend engineering capabilities. Built from the ground up, it avoids standard templates to deliver a custom, premium feel with tailored animations, a curated color palette, and a seamless user experience across all devices. 

It aims to serve as undeniable proof of competence in advanced frontend development and motion design.

### 🎯 Key Features

- **Premium Aesthetics:** Tailored dark/light mode palette, modern typography (Inter/Geist), and sophisticated layouts.
- **Advanced Motion Design:** Scroll-triggered reveals, smooth text splitting, and a custom interactive cursor with blending modes, all powered by GSAP.
- **Fluid Smooth Scrolling:** Integrated with Lenis for a buttery-smooth scrolling experience that enhances the parallax and motion effects.
- **Fully Responsive Architecture:** Mobile-first design that adapts flawlessly to tablet and desktop environments without compromising the animation experience.
- **Dynamic Content:** Data-driven sections for "Works" and "Skills" allowing for easy updates and scalability.
- **Optimized Performance:** Leveraging Next.js App Router, optimized asset rendering, and component-level code splitting.

## 🚀 Getting Started

Follow these instructions to set up the project locally.

### Prerequisites

Ensure you have Node.js installed (v18.x or later recommended).

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/hermouchDev/My-Portfolio.git
   cd My-Portfolio
   ```

2. **Install dependencies**
   Using npm:
   ```bash
   npm install
   ```
   *Or using yarn/pnpm/bun:*
   ```bash
   yarn install
   # or
   pnpm install
   # or
   bun install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Explore the app**
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

## 📂 Project Structure

```text

│   ├── app/                # Next.js App Router pages and global layouts

└── package.json            # Project dependencies and scripts
```
