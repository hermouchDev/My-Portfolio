# Abdelmajid Hermouch - Premium Portfolio

Welcome to the source code of my personal portfolio website, a modern, highly interactive, and visually stunning web experience built with Next.js, React, and GSAP.

## 🚀 Live Demo

[Live Website](https://abdelmajidhermouch.vercel.app/)

## 🔗 Repository

[GitHub Repository](https://github.com/hermouchDev/My-Portfolio)

## 🛠️ Built With

- **Next.js** - React framework for production
- **React** - UI library
- **Tailwind CSS** - Utility-first CSS framework
- **GSAP (GreenSock Animation Platform)** - Professional-grade JavaScript animation for the web
- **Lenis** - Smooth scrolling library
- **TypeScript** - Strongly typed programming language that builds on JavaScript

## 🌟 Features

- **Premium Aesthetics:** Dark mode, tailored color palette, modern typography.
- **Advanced Animations:** Scroll-triggered reveals, smooth text splitting, interactive custom cursor with blending modes.
- **Fully Responsive:** Optimized layouts for mobile, tablet, and desktop viewing without compromising the animation experience.
- **Dynamic Projects Showcase:** Elegant horizontal scrolling sections and comprehensive project detail views.

## 💻 Getting Started
